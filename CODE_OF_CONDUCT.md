# GeoTask社区行为准则 / Code of Conduct

## 我们的承诺

GeoTask欢迎不同背景、经验和观点的参与者。无论参与者的年龄、身体状况、民族、性别认同与表达、教育背景、国籍、外貌、宗教、职业、技术水平或其他个人特征如何，我们都致力于提供开放、友善、安全和专业的协作环境。

## 期望行为

参与GeoTask社区时，请：

- 使用尊重、清晰和建设性的语言；
- 针对问题、证据和实现讨论，不攻击个人；
- 接受不同技术路径和应用背景；
- 在指出问题时尽量提供可复现信息；
- 尊重开源边界、客户数据、隐私和知识产权；
- 对新参与者保持耐心，并帮助其理解项目约束；
- 在发现安全或敏感问题时使用合适的私密渠道。

## 不可接受行为

以下行为不可接受：

- 骚扰、歧视、侮辱、威胁或持续的人身攻击；
- 未经允许公开他人的私人信息；
- 提交客户数据、真实凭据、模型密钥或其他敏感材料；
- 故意绕过项目的安全、许可或公开边界；
- 在技术讨论中持续制造敌意或干扰协作；
- 其他可合理视为不专业或不安全的行为。

## 适用范围

本准则适用于GitHub Issue、Pull Request、Discussion、代码审查、项目活动以及代表GeoTask进行的公开交流。

## 处理方式

维护者可以删除不当内容、要求修改表达、临时限制参与，或在严重情况下永久禁止参与。处理时应尽量保持一致、克制，并保护报告者隐私。

行为问题可通过仓库维护者公开资料中的私密联系方式报告。安全漏洞请按照[SECURITY.md](SECURITY.md)处理，不要在公开Issue中披露。

## Our pledge

GeoTask welcomes contributors with different backgrounds, experience levels, and viewpoints. We are committed to an open, friendly, safe, and professional collaboration environment.

## Expected behavior

Participants should:

- communicate respectfully and constructively;
- discuss problems, evidence, and implementations rather than attacking people;
- accept different technical approaches and application contexts;
- provide reproducible information when reporting problems;
- respect privacy, customer data, open-source boundaries, and intellectual property;
- help new contributors understand project constraints;
- use private channels for security or sensitive disclosures.

## Unacceptable behavior

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, disclosure of private information, submission of credentials or customer data, intentional circumvention of project boundaries, and sustained disruption of technical collaboration.

## Scope and enforcement

This code applies to issues, pull requests, discussions, reviews, project events, and public representation of GeoTask. Maintainers may remove content, request changes, restrict participation, or ban participants when necessary. Reports should be handled consistently and with appropriate privacy.
