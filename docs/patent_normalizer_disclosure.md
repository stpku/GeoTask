# 专利交底书草案

## 一种面向空间任务的智能模型输出归一化与确定性验证方法、系统及存储介质

---

### 一、技术领域

本发明属于空间信息处理与人工智能交叉领域，具体涉及一种将大语言模型（LLM）
产生的非结构化空间推理结果转化为可验证的结构化空间任务结果的方法与系统。

---

### 二、背景问题

当前大语言模型（如 GPT、DeepSeek 等）已能够基于结构化的空间任务输入产生正确的
空间推理结果。然而，模型输出存在以下问题：

1. **格式不统一**：输出可能是自然语言（中文/英文）、YAML 片段、Markdown 列表或混合格式；
2. **不可信**：模型可能产生幻觉或计算错误；
3. **不可自动消费**：下游业务系统无法稳定解析非结构化输出；
4. **缺乏验证机制**：缺少将模型声明与确定性计算结果进行交叉校验的手段。

---

### 三、发明目的

本发明的目的在于提供一种方法，能够：

1. 从大模型产生的非结构化输出中抽取结构化空间测量值和空间关系判断；
2. 将抽取结果与本地确定性算子计算结果进行交叉校验；
3. 输出带有 verified/contradicted/need_review 状态的统一空间任务结果。

---

### 四、技术方案

本发明提供一种面向空间任务的智能模型输出归一化与确定性验证方法，包括以下步骤：

**S1：接收输入**
- 接收大模型产生的非结构化文本输出；
- 可选地接收对应的 GeoTask Core 结构化空间任务文档。

**S2：语义块识别与抽取**
- 从文本中识别距离测量值（支持中文"米"、英文"meter"、"m"等单位标识）；
- 从文本中识别空间相交判断（区分"相交"与"不相交"，中文否定优先于肯定）；
- 从文本中识别算子引用（如 distance_2d、line_intersects_rect）；
- 从文本中识别对象引用（如 起飞点→takeoff、学校→school 等中英映射）。

**S3：本地确定性验证**
- 当 S1 中提供了 GeoTask 文档时，调用本地确定性算子运行器；
- 将抽取的数值型测量值与本地结果比较（使用容差阈值）；
- 将抽取的布尔型关系判断与本地结果比较；
- 为每个测量生成 verified / contradicted / need_review 状态。

**S4：统一结果输出**
- 输出结构化的 GeoTask Result，包含 measurements、conclusion、verified_by；
- 每个 measurement 包含 status、expected_value、difference 等字段；
- conclusion 包含 overall_status 和 review_reasons。

---

### 五、系统模块

1. **Normalizer 模块**：负责文本语义抽取（距离、相交判断、算子引用、对象引用）
2. **Verifier 模块**：负责本地确定性算子复核（调用已有 runner）
3. **Result Schema 模块**：定义统一结果结构（状态常量、构建函数）
4. **CLI 模块**：提供命令行接口，支持 --geotask 参数进行验证增强

---

### 六、实施例

**实施例 1 — 正确输出验证**

输入：
- 模型输出文本："起飞点到学校的距离为 144.22 米。航线与矩形区域相交。"
- GeoTask 文档：geotask_core_lite.yaml

处理过程：
1. 抽取距离值 144.22、相交判断 true
2. 检测算子引用 distance_2d、line_intersects_rect
3. 本地 runner 计算得距离 144.22、相交 true
4. 比较：差异 0.0 ≤ 容差 → verified

输出：overall_status = verified

**实施例 2 — 错误输出检测**

输入：
- 模型输出文本："起飞点到学校的距离为 150 米。"
- GeoTask 文档：同上

处理过程：
1. 抽取距离值 150.0
2. 本地 runner 计算得 144.22
3. 比较：差异 5.78 > 容差 0.05 → contradicted

输出：overall_status = contradicted

---

### 七、有益效果

1. **格式无关**：支持中文自然语言、英文、YAML、Markdown 等多种输出格式；
2. **可验证**：将模型声明与确定性计算交叉校验，发现冲突；
3. **轻量化**：无需重 GIS 依赖，纯 Python 实现；
4. **可扩展**：支持新增算子、新增对象类型、新增语言支持。

---

### 八、拟保护点

1. 智能模型输出语义块识别方法（距离、关系判断、算子、对象）
2. 空间测量值抽取的优先级规则（上下文优先于坐标值）
3. 空间关系判断的双语否定优先机制
4. 模型声明与本地确定性算子交叉校验流程
5. verified / contradicted / need_review 三态生成规则
6. 统一空间任务结果结构
7. 算子引用检测与缺失告警机制
8. 中英文对象名称映射方法

---

### 九、权利要求草案

**权利要求 1**：一种面向空间任务的智能模型输出归一化与确定性验证方法，
其特征在于，包括：
- 接收大模型产生的非结构化文本输出和可选的结构化空间任务文档；
- 从文本中抽取空间测量值和空间关系判断；
- 当接收到结构化空间任务文档时，调用本地确定性算子进行复核；
- 输出包含 verified/contradicted/need_review 状态的统一空间任务结果。

**权利要求 2**：如权利要求 1 所述的方法，其中所述空间测量值抽取包括：
- 使用正则表达式匹配距离数值及其单位标识；
- 使用上下文优先级规则区分最终距离值与中间坐标值。

**权利要求 3**：如权利要求 1 所述的方法，其中所述空间关系判断抽取采用
否定优先策略，即在中文文本中先检测"不相交"等否定模式，再检测"相交"等
肯定模式。

**权利要求 4**：如权利要求 1 所述的方法，其中所述本地确定性算子复核包括：
- 对数值型测量使用容差阈值比较；
- 对布尔型测量使用等值比较；
- 对缺失值标记为 need_review。

**权利要求 5**：如权利要求 1 所述的方法，其中所述统一空间任务结果包含
overall_status 字段，其值根据各 measurement 的状态按照
contradicted > need_review > verified 的优先级计算得出。

**权利要求 6**：一种计算机可读存储介质，其上存储有计算机程序，该程序被
处理器执行时实现权利要求 1-5 中任一项所述的方法。

**权利要求 7**：一种面向空间任务的智能模型输出归一化与确定性验证系统，
包括文本抽取模块、本地验证模块和结果输出模块，用于执行权利要求 1-5 中
任一项所述的方法。
