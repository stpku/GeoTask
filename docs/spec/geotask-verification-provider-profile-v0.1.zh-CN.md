# GeoTask验证提供方接口规范 v0.1

## 状态

本规范定义GeoTask核心与外部验证能力之间的公共、只读、失败关闭接口。

公共接口包含四类注册制品：

1. `geotask.verification-provider-descriptor`：验证提供方描述符；
2. `geotask.verification-request`：验证请求；
3. `geotask.verification-response`：验证响应；
4. `geotask.assurance-profile`：可信保证档案。

本规范不定义生产级验证提供方市场、凭据存储、网络传输、计费、行业监管规则或行动执行器。

## 核心原则

验证提供方可以说明自己观测了什么、检查了什么，但不能自行声明：

- 自己已经构成独立验证；
- 自己的可信保证等级已经提升；
- 生产结果已经发布；
- 行动已经获得授权；
- 行动已经执行。

是否满足独立验证要求，必须由验证响应之外的可信保证评估，根据调用方预先编写的可信保证档案判断。

## 验证提供方描述符

描述符声明：

- 稳定的提供方标识和版本；
- 提供方类型；
- 支持的能力和验证方法；
- 独立性分组；
- 可复现性状态；
- 校准状态；
- 有效期限；
- 审计和凭据边界；
- 固定为假的外部副作用许可。

支持的提供方类型包括确定性算子、规则引擎、权威数据提供方、传感器数据提供方、本地预测模型和人工复核。

模拟提供方必须声明尚未达到生产可用状态。

## 验证请求

验证请求绑定：

- 一个待验证命题；
- 输入制品及其精确SHA-256摘要；
- 一个验证方法；
- 必需能力；
- 允许的提供方类型；
- 一份精确绑定的可信保证档案；
- 截止时间；
- 禁止外部副作用和禁止行动授权的安全标志。

核心只校验请求，不会把请求提交给外部提供方。

## 验证响应

验证响应必须精确绑定验证请求和提供方描述符的原始文件字节，并记录：

- 提供方本地结果状态；
- 带来源有效期的结果；
- 验证方法和证据引用；
- 从描述符继承的独立性、可复现性和校准声明；
- 诊断信息和完成时间。

以下字段必须始终为假：

- `independently_verified`
- `production_output_released`
- `action_authorized`
- `action_executed`

绑定校验会拒绝提供方在响应中擅自更改独立性分组、可复现性或校准状态。

## 可信保证档案

可信保证档案由调用方编写，而不是由验证提供方编写。它声明：

- 最少提供方数量；
- 最少独立分组数量；
- 可接受的提供方类型；
- 时效与最大数据年龄要求；
- 可复现性要求；
- 校准要求；
- 冲突处理规则；
- 可用输出、阻断输出和阻断动作；
- 可信保证不足时的下一步动作。

公共参考评估器不会自行推断来源优先级，也不会对冲突数值取平均。若多个新鲜、合规且相互独立的响应仍然冲突，结果保持未知，或按档案中明确声明的规则标记为矛盾。

## 命令行

```bash
geotask provider inspect --profile --format json
geotask provider inspect provider-descriptor.json
geotask provider check provider-descriptor.json verification-request.json
geotask provider validate verification-response.json \
  --request verification-request.json \
  --descriptor provider-descriptor.json
```

所有命令均为只读操作，不提交请求、不获取外部证据、不调用网络服务、不发布生产结果、不授权行动，也不执行副作用。

## GT29参考案例

GT29使用完全虚构的数据：

- 模拟权威气象服务：8米/秒；
- 模拟现场传感器：13米/秒；
- 任务风速上限：12米/秒。

两个响应都处于有效期内，也来自两个不同的独立性分组，但数值彼此冲突。因此天气结论保持未知，天气核验输出、自动起飞授权和起飞指令继续阻断，下一步是请求第三个独立气象验证来源。

## GT30参考案例

GT30加入第三个虚构独立来源：移动测风激光雷达同样给出13米/秒。三个响应全部新鲜、可复现、满足校准要求，并来自三个独立分组，但整体仍包含8米/秒和13米/秒两个不同数值。

可信保证档案v0.1没有声明多数表决，也不会静默删除少数来源。因此二比一不能自动升级为已核验，结果继续保持未知，下一步改为请求显式气象裁决。

## 公开边界

公共规范只包含接口、严格校验、离线参考逻辑和虚构案例。生产连接器、凭据、来源质量评分、跨来源治理、行业规则、客户流程、生产结果发布和行动执行均不属于GeoTask核心。
