## 3. Key Benchmark Findings

All metrics below are computed from `encoding_benchmark_v0_1_results.json` — real benchmark data generated by deterministic simulated runs. No manual fabrication.

### Token Cost

| Encoding | Avg Input Tokens | Avg Output Tokens | **Avg Total Tokens** |
|----------|-----------------:|------------------:|---------------------:|
| natural_language | **174** | **230** | **404** |
| geotask_yaml | **197** | **65** | **262** |
| compact_dsl | **79** | **12** | **90** |

### Token Reduction vs Natural Language

| Comparison | Token Reduction | Compression Ratio |
|------------|----------------:|------------------:|
| compact_dsl vs natural_language | **77.6%** | **4.5×** |
| geotask_yaml vs natural_language | **35.1%** | **1.5×** |

### Normalization & Verification

| Encoding | Normalization Success Rate | Verification Success Rate (Status Match) | Avg Benchmark Score (0–100) |
|----------|---------------------------:|----------------------------------------:|----------------------------:|
| natural_language | **100%** | **100%** | **79.6** |
| geotask_yaml | **100%** | **100%** | **81.9** |
| compact_dsl | **100%** | **100%** | **95.0** |

### Error Detection

- **Wrong distance** (case_002): Flagged as `contradicted` in 3/3 encodings.
- **Wrong boolean** (case_003): Flagged as `contradicted` in 3/3 encodings.
- **Missing operator reference** (case_004): `operator_reference_missing` detected in 3/3 encodings.

## 5. What This Evidence Proves

**English:**

> This evidence supports the engineering claim that task-related spatial encodings can reduce input/output token cost while preserving normalizable and verifiable output structure under deterministic simulated conditions.

**中文:**

> 该证据支撑一个工程性主张：在确定性模拟条件下，任务相关空间编码能够降低输入/输出 token 成本，同时保持可归一化、可验证的输出结构。

## 6. What This Evidence Does NOT Prove

- ❌ Does **not** prove general LLM accuracy improvement.
- ❌ Does **not** prove applicability to all spatial tasks.
- ❌ Does **not** prove compact DSL is optimal across all LLM models.
- ❌ Does **not** replace subsequent live LLM benchmark evaluation.
- ❌ Does **not** replace formal patent prior art search by a qualified patent attorney.
