答对，不等于已经通过验证

模型算出了 144.22 米，谁来证明它没算错？

同一份空间任务，一条路径交给模型，一条路径由浏览器本地确定性复算。

A = (0, 0)　B = (120, 80)　distance_2d

本期任务

计算起飞点与学校之间的二维欧氏距离。坐标已明确为本地平面坐标，单位为米。

起飞点 takeoff(0, 0)
学校 school(120, 80)
指定算子distance_2d
确定性结果144.22 meter

第一步：让模型执行任务

1
复制完整 GT02 任务主按钮会复制任务并尝试打开 DeepSeek。
2
粘贴、发送并记下数值只需记住模型给出的距离，例如 144.22。

微信内无法打开时，请点右上角“···”，选择“在浏览器打开”。

查看将被复制的完整 GeoTask 
geotask:
  id: "gt02-independent-distance-verification"
  name: "GT02 Independent Distance Verification"
  schema_version: "1.0"

space:
  crs:
    type: "local_cartesian"
    identifier: "local_xy_m"
  horizontal_unit: "meter"
  coordinate_order: ["x", "y"]

objects:
  takeoff:
    type: "point"
    coordinates: [0, 0]
  school:
    type: "point"
    coordinates: [120, 80]

operator_set:
  - distance_2d

tasks:
  - id: "verify_takeoff_to_school_distance"
    family: "measurement"
    goal: "Calculate the Euclidean distance between takeoff and school."
    assertions:
      - id: "takeoff_to_school_distance"
        operator: "distance_2d"
        object_refs: ["takeoff", "school"]
        unit: "meter"

execution:
  mode: "model_then_local_verify"

output_contract:
  format: "structured"
  required_fields:
    - "takeoff_to_school_distance"
    - "assurance_level"
    - "verification_status"

instructions_for_model:
  - "Return the numeric distance in meter."
  - "Mark the model-produced result as model_generated."
  - "Do not claim local_deterministic verification unless a separate deterministic executor has run."

第二步：用另一条计算链独立复算

把模型给出的距离数值填入下面。页面会在你的浏览器中执行固定的二维距离公式，不调用任何后台。

meter
验证结果 等待输入
模型结果—
本地确定性结果144.222051 m
绝对差异—
比较容差0.01 m

模型结果属于 model_generated；点击“本地验证”后，页面会增加一条 local_deterministic 证据。

这里演示的不是“让 AI 再想一次”

模型路径
model_generated
模型理解任务、选择步骤并生成候选结果。
确定性路径
local_deterministic
固定程序按照明确公式独立计算，相同输入得到相同输出。

本页用浏览器 JavaScript 演示独立复算；GeoTask Core 的正式确定性执行由本地 Python 算子完成。两者使用相同的二维欧氏距离语义。
