地图上重叠，空中就一定冲突吗？

同一片二维区域，飞行高度100–150米，限制高度300–500米。二维完全重叠，不等于三维空间发生冲突。

altitude_conflict = false

同一个任务，必须同时看俯视图和侧视图

两个对象的平面范围完全相同。只看地图，它们似乎完全冲突；加入高度后，结论反而是false。

第一步：让模型执行GT04

任务明确说明二维范围相同，并要求使用altitude_overlap判断两个高度区间是否重叠。

得到模型的true或false后，请返回本页完成独立验证。

查看将被复制的完整 GeoTask 
geotask:
  id: "gt04-2d-overlap-3d-separation"
  name: "GT04 2D Overlap but 3D Separation"
  schema_version: "1.0"

space:
  crs:
    type: "local_cartesian"
    identifier: "local_xy_m"
  horizontal_unit: "meter"
  vertical_unit: "meter"

objects:
  flight_footprint:
    type: "rect"
    bbox: [0, 0, 300, 200]
  restricted_footprint:
    type: "rect"
    bbox: [0, 0, 300, 200]
  flight_altitude:
    type: "altitude_interval"
    min_altitude: 100
    max_altitude: 150
    unit: "meter"
  restricted_altitude:
    type: "altitude_interval"
    min_altitude: 300
    max_altitude: 500
    unit: "meter"

context:
  horizontal_footprints_overlap: true
  horizontal_relation: "identical"

operator_set:
  - altitude_overlap

tasks:
  - id: "verify_altitude_conflict"
    family: "vertical_topology"
    goal: "Given identical horizontal footprints, determine whether the altitude ranges overlap."
    assertions:
      - id: "altitude_conflict"
        operator: "altitude_overlap"
        object_refs: ["flight_altitude", "restricted_altitude"]
        expected_type: "bool"

execution:
  mode: "model_then_local_verify"

output_contract:
  format: "structured"
  required_fields:
    - "altitude_conflict"
    - "assurance_level"
    - "verification_status"

instructions_for_model:
  - "Do not infer a 3D conflict from horizontal overlap alone."
  - "Compare the two closed altitude intervals."
  - "Boundary contact counts as altitude overlap."
  - "Return altitude_conflict as true or false."
  - "Mark the model-produced result as model_generated."
  - "Do not claim local_deterministic verification unless a separate deterministic executor has run."
