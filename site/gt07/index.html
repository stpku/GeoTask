不知道，不等于false；也不等于true

一个必要条件算不出来，AI还能硬给答案吗？

路线和高度都已验证为true，但限制时段的可信状态尚未确认。GT07让unknown继续传播，而不是偷偷改写成布尔值。

full_conflict_status = unverifiable

两项已验证，一项不可验证

预设时间区间看起来会重叠，但其来源还未得到确认，因此时间算子不能被当作可靠证据执行。

路线相交true
高度重叠true
时间条件unknown
true ∧ true ∧ unknown最终结论：不可验证

第一步：把完整GT07交给模型

模型必须区分“预设区间在数值上重叠”和“该区间已经成为可验证证据”这两件事。

模型可以回答true、false或unverifiable。返回本页后选择对应候选。

查看将被复制的完整 GeoTask
geotask:
  id: "gt07-unverifiable-constraint"
  name: "GT07 Unverifiable Constraint"
  schema_version: "1.0"

space:
  crs:
    type: "local_cartesian"
    identifier: "local_xy_m"
  horizontal_unit: "meter"
  vertical_unit: "meter"

objects:
  route:
    type: "polyline"
    coordinates:
      - [-200, 0]
      - [400, 0]
  restricted_zone:
    type: "rect"
    bbox: [250, -100, 350, 100]
  flight_altitude:
    type: "altitude_interval"
    min: 100
    max: 150
  restricted_altitude:
    type: "altitude_interval"
    min: 120
    max: 180
  flight_time:
    type: "time_interval"
    start: "08:00"
    end: "09:00"
  provisional_restricted_time:
    type: "time_interval"
    start: "08:30"
    end: "10:00"

operator_set:
  - line_intersects_rect
  - altitude_overlap
  - time_overlap

tasks:
  - id: "evaluate_required_conditions"
    assertions:
      - id: "route_intersects_zone"
        operator: "line_intersects_rect"
        object_refs: ["route", "restricted_zone"]
      - id: "altitude_conflict"
        operator: "altitude_overlap"
        object_refs: ["flight_altitude", "restricted_altitude"]
      - id: "temporal_conflict"
        operator: "time_overlap"
        object_refs: ["flight_time", "provisional_restricted_time"]
        condition: "restricted_schedule_verified"

execution:
  mode: "model_then_local_verify"

extensions:
  decision_rule:
    id: "full_conflict"
    logic: "three_valued_and"
    expression: "route_intersects_zone AND altitude_conflict AND temporal_conflict"
    unknown_policy: "propagate"
  evidence_note: "The restricted schedule interval is provisional and has not been verified."

output_contract:
  format: "structured"
  required_fields:
    - "route_intersects_zone"
    - "altitude_conflict"
    - "temporal_conflict_status"
    - "full_conflict_status"
    - "verification_status"

instructions_for_model:
  - "Do not treat unverified evidence as a verified boolean input."
  - "If a required condition cannot be verified, preserve it as unverifiable."
  - "Apply three-valued AND with unknown propagation."
  - "Do not silently replace unknown with true or false."
  - "Mark model-produced conclusions as model_generated."
  - "Do not claim local_deterministic verification unless a separate executor has run."

第二步：本地验证三值结论

请选择模型的最终候选。页面会执行两项确定性算子，并用与Core一致的条件门控保留不可验证状态。

验证结果等待选择
模型最终候选—
本地最终状态unverifiable
局部证据T / T / U
执行状态partial

候选来源：model_generated；本地算子、条件门控和三值组合：local_deterministic。

“不可验证”不是“没有冲突”，也不是“存在冲突”。它表示当前证据不足以支持任何一个布尔结论，需要补充或确认限制时段信息。
