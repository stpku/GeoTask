配送机器人 · 几何距离与对象可达性

地图上只有50米，机器人为什么要绕行300米？

收货点近在眼前，但直线路径穿过台阶、围栏和机动车道。对轮式配送机器人而言，“离得近”不等于“走得到”。

selected_action = follow_accessible_network

本案例不新增网络最短路Core算子。Core真实计算直线距离和五段网络边长度，任务层验证边均可通行并汇总为300米。

第一步：让模型选择机器人路线

模型可以选择直线前往、沿可通行网络绕行，或者横穿机动车道。候选路线必须同时满足机器人能力和环境约束。

得到模型建议后返回本页，选择对应路线并验证。

查看将被复制的完整 GeoTask
geotask:
  id: "gt11-robot-accessible-route"
  name: "GT11 Delivery Robot Accessible Route"
  schema_version: "1.0"

application_context:
  scenario: "delivery_robot_accessible_route"
  environment: "campus_delivery"

robot_profile:
  mobility: "wheeled"
  can_use_stairs: false
  can_cross_fence: false
  can_enter_motor_vehicle_lane: false
  maximum_step_height_cm: 2

direct_path_constraints:
  direct_path_distance_m: 50
  blocked_by: ["stairs", "fence", "motor_vehicle_lane"]
  direct_path_accessible: false

accessible_network:
  route_node_refs: ["robot_start", "waypoint_1", "waypoint_2", "waypoint_3", "waypoint_4", "delivery_target"]
  segment_lengths_m: [100, 75, 50, 25, 50]
  total_distance_m: 300
  all_edges_accessible: true

route_comparison:
  euclidean_distance_m: 50
  accessible_route_distance_m: 300
  detour_ratio: 6
  shortest_geometric_route_accessible: false

navigation_plan:
  selected_action: "follow_accessible_network"
  rejected_actions: ["take_direct_line", "cross_motor_vehicle_lane"]
  planned_distance_m: 300
  next_action: "navigate_network"
  expected_status: "reachable"

instructions_for_model:
  - "Choose one action from take_direct_line, follow_accessible_network, or cross_motor_vehicle_lane."
  - "Do not equate Euclidean proximity with robot accessibility."
  - "Preserve robot mobility constraints and route provenance."
  - "Mark model-produced fields as model_generated."
  - "Do not claim local_deterministic verification unless a separate executor has run."

GT11只验证给定可通行网络。真实配送还需考虑道路动态占用、坡度、路面、门禁、电梯、天气、行人和实时重规划。
