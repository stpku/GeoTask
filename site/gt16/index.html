低空飞行 · 计划验证与动态复核

计划已经安全，为什么无人机仍要持续监测？

初始计划中，两机交叉区时间间隔为120秒，满足60秒最低要求；但A机最新延误40秒后，预测间隔只剩80秒。结论尚未反转，安全余量却已经变化。

initial verification → new state → impact analysis → local recheck → action gate

系统保留“当前仍可通行”的结论，但废止“初始计划永久安全”和“无需继续监测”两个输出。

保留已验证的空间关系
持续接收最新遥测
间隔≤60秒时重新门控

GeoTask在这里不是把结论从安全直接改成冲突，而是定位变化、计算影响范围，并把后续行动限制在仍有证据支持的边界内。
