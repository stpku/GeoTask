低空飞行 · 路线、高度与时间联合判断

两架无人机路线相交，就一定会相撞吗？

两条路线经过同一个交叉点，高度区间也发生重叠，但A机在09:01前离开，B机09:03才进入。空间相交不等于同一时刻占用。

collision = horizontal_crossing AND altitude_overlap AND temporal_overlap

同一个交叉点，不同的到达时间

水平路线相交
true
高度区间重叠
true
交叉时间重叠
false
true AND true AND false → collision_conflict = false

时间间隔已经满足最低要求

A机
09:00—09:01
B机
09:03—09:04

实际间隔2分钟，最低要求1分钟；当前时刻表证据状态为 current_and_verified。

flight_gate = open_with_verified_separation

系统不应宣称“碰撞已验证”，也不需要在没有时间冲突时强制两架无人机紧急停止。

保持交叉时窗
监控到达偏差
偏差超限重新计算

时间错开成立的前提是计划能够被执行。任何延误、提速或轨迹偏移都可能消耗间隔，需要在线重算。

得到模型建议后返回本页，选择对应结论并验证。
