应急救援 · 路线与设备能力绑定

最短路线已经找到，为什么救援机器人仍然不能进入？

工业厂房发生火灾。地图给出的最短路线只有120米，但它穿过120℃高温区，而救援机器人的耐受上限只有80℃。

geometrically shortest ≠ environmentally safe ≠ executable for this robot

最短路线穿过高温危险区

最短路线到达目标
true
最短路线穿越危险区
true
最短路线可执行
false
true AND NOT true AND (120℃ ≤ 80℃) → false

更长的路线，才是当前可执行路线

最短路线

120米

穿过高温区，最高120℃，超过机器人80℃上限。

shortest_route_executable = false

安全路线

260米

绕开高温区，最高60℃，处于机器人能力范围内。

safe_route_executable = true

路线优化目标不能只写“最短”。对于真实设备，应首先满足安全与能力约束，再在可行解中优化距离或时间。

第一步：让模型选择行动

得到模型建议后返回本页，选择对应动作并验证。

查看完整 GeoTask 摘要
geotask:
  id: "gt18-rescue-robot-shortest-route-hazard"
  schema_version: "1.0"

route_metrics:
  shortest_route_length_m: 120
  safe_route_length_m: 260
  shortest_route_is_geometrically_shortest: true
  shortest_route_intersects_high_temperature_zone: true
  safe_route_intersects_high_temperature_zone: false

environment_evidence:
  shortest_route_max_temperature_c: 120
  safe_route_max_temperature_c: 60
  evidence_status: "verified"

robot_capability:
  robot_id: "rescue_robot_r7"
  maximum_operating_temperature_c: 80

feasibility_rule:
  expression: "route_reaches_target AND NOT route_intersects_hazard AND route_max_temperature_c <= robot_maximum_operating_temperature_c"
  shortest_route_executable: false
  safe_route_executable: true

task_gate:
  status: "open_for_safe_route_entry"
  selected_action: "enter_via_safe_route"
  rejected_actions:
    - "enter_via_shortest_route"
    - "abort_rescue_mission"
  blocked_outputs:
    - "authorize_shortest_route_entry"
    - "ignore_verified_hazard"
  next_action: "dispatch_robot_via_safe_route"
  expected_status: "verified_safe_route_entry"

instructions_for_model:
  - "Choose one action from enter_via_shortest_route, abort_rescue_mission, or enter_via_safe_route."
  - "Check route reachability, hazard intersection, and robot temperature capability independently."
  - "Do not equate geometric shortest path with executable route."
  - "Mark model-produced fields as model_generated."
  - "Do not claim local_deterministic verification unless a separate executor has run."

第二步：验证模型动作

验证结果等待选择
模型候选动作—
本地任务动作enter_via_safe_route
机器人温度上限80℃
安全路线最高温度60℃

候选来源：model_generated；路线距离和危险区相交：local_deterministic；温度证据与设备能力：application_verified。

GT18演示的是静态路线级验证。真实火场还需要持续更新温度、烟气、结构稳定性、通信质量、电量和撤退通道状态。
