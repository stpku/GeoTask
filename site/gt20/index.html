智能驾驶 · 路口入口门控

车辆已经获得绿灯，为什么仍然不能进入路口？

信号许可有效，但下游排队已经回溢。出口到队尾只剩4米，车辆连同安全缓冲需要6.8米。

green signal permission ≠ downstream exit clearance ≠ intersection entry authorization

绿灯成立，下游驶离条件不成立

绿灯许可有效
true
下游出口净空
false
入口授权
false
true AND false AND (4.0 ≥ 6.8) → intersection_entry_authorized = false

等待必须发生在停止线之前

驶入后等待

禁止

车辆会占用冲突区，阻断横向交通，并可能在相位切换后滞留路口。

intersection_entry_command = blocked

线前等待

可恢复

持续核验绿灯、下游净空和3秒内的新鲜排队证据，条件恢复后再进入。

resume_when = signal AND exit_clear AND storage

绿灯给出的是信号层通行许可，不承诺下游道路能够容纳整车。车辆必须先证明可以完整驶离冲突区。

第一步：让模型选择行动

得到模型建议后返回本页，选择对应动作并验证。

查看完整 GeoTask 摘要

  id: "gt20-vehicle-green-light-downstream-blockage"
  schema_version: "1.0"

extension_profile:
  id: "geotask.control"
  version: "1.0"

signal_evidence:
  signal_aspect: "green"
  signal_permission_valid: true
  evidence_status: "verified"

core_checks:
  green_phase_matches_entry_window: true
  path_intersects_downstream_queue: true
  available_downstream_storage_m: 4.0

vehicle_envelope:
  vehicle_length_m: 4.8
  minimum_exit_buffer_m: 2.0
  required_storage_m: 6.8

downstream_state:
  queue_spillback_present: true
  downstream_exit_clear: false
  freshness_limit_seconds: 3

entry_rule:
  expression: "signal_permission_valid AND downstream_exit_clear AND available_storage_m >= required_storage_m"
  storage_sufficient: false
  intersection_entry_authorized: false

task_gate:
  status: "blocked_pending_downstream_clearance"
  selected_action: "wait_before_stop_line_and_recheck_downstream"
  rejected_actions:
    - "enter_intersection_because_green"
    - "enter_intersection_and_wait_inside"
  blocked_outputs:
    - "intersection_entry_command"
    - "follow_green_without_exit_check"
  required_controls:
    - "remain_before_stop_line"
    - "retain_signal_and_queue_evidence"
    - "recheck_downstream_storage"
    - "enter_only_when_full_vehicle_can_clear_junction"
    - "reevaluate_if_signal_phase_changes"
  resume_when: "signal_permission_valid == true AND downstream_exit_clear == true AND available_storage_m >= 6.8 AND downstream_evidence_age_seconds <= 3"
  next_action: "recheck_signal_and_downstream_clearance"
  expected_status: "verified_intersection_hold"

instructions_for_model:
  - "Choose one action from enter_intersection_because_green, enter_intersection_and_wait_inside, or wait_before_stop_line_and_recheck_downstream."
  - "Check signal permission and downstream clearance independently."
  - "Do not infer exit storage from a green signal."
  - "Mark model-produced fields as model_generated."
  - "Do not claim local_deterministic verification unless a separate executor has run."
