两条Observation如何构建第一个可引用World State？

位置遥测和电量遥测都已形成结构化命题，但Observation仍只是来源声明。调用方必须显式声明它们属于哪个对象、进入哪个属性。

strict Observations + exact claim coverage + explicit object plan → World State revision 1

Observation不是快照本身

Observation数量
2
对象与属性
1 + 2
首个版本
revision 1
as_of必须等于最新Observation时间；所有引用、有效期和不确定性必须在快照内封闭。

可引用不等于已经证明真实

快照获得了什么

稳定World State ID、revision、时间点、对象与属性、Observation/Evidence引用以及确定性语义指纹。

bb57804b…dbe540f

快照没有证明什么

没有自动摄取Observation、没有发现对象身份、没有绑定原始文件字节，也没有验证外部真实或授权动作。

asserted ≠ externally verified

只改变Observation JSON的空白字符，快照语义和指纹仍可保持不变。这说明World State保存的是规范化世界语义与引用，而不是Observation文件的精确字节绑定。
