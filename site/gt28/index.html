把技术预检结论错误提升为行政、运行和任务授权。

根据安全结果推断授权存在

用“路线安全、天气良好”替代缺失的权威授权证据。

GeoTask将“可计算条件”“可发布输出”“行动资格”和“实际执行”分成不同层级，前一层通过不会自动跃迁到后一层。

门禁链

route/weather checks verified → route_weather_precheck eligible → 5 authorization identifiers unknown → automatic_takeoff_authorization blocked → takeoff_command blocked → action_executed false

控制评估的下一步是request_authorization_bundle_and_reverify，不是发送起飞命令。

即使未来五项授权全部变为true，公共控制评估也只会把输出标记为eligible；它仍不会联系真实主管部门、发布生产输出，不会自行发送起飞指令或执行起飞。

技术实现：为什么eligible仍不等于执行？

Control Evaluation只计算门禁表达式并记录blocked或eligible outputs，JSON Schema将action_executed固定为false。Verification Session再把预检输出与自动起飞资格分别记录，既不释放生产输出，也不调用执行系统。
